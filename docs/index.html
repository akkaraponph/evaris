Quick start

Install the CLI

Use npm with Node.js 18+ on Linux or macOS, or download an archive from GitHub.

Check the npm release
npx --yes evaris-cli@latest --version

Install for a project or globally · Archives

Run the offline demo

Use Go 1.27.4+ on your PATH. The demo grades authored controls and prints the report path.

Run the offline demo
git clone https://github.com/refactorroom/evaris.git
cd evaris
go run ./examples/offline

The demo runs locally without a model API.
