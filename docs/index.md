# Evaris

Evaris is an open-source framework for reproducible agent and skill evaluations. It combines deterministic checks, independent review, and evidence to assess engineering outcomes.

## Get started

Find installation instructions and examples in the [Evaris README](https://github.com/refactorroom/evaris#readme). Evaris supports Linux and macOS.
